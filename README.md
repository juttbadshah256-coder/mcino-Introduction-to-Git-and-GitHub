# Travel Recommendation

## Project Name

Travel Recommendation

## Project Description

Travel Recommendation is a website that helps users discover
beautiful travel destinations and find suitable places for their
next trip.

## Features

- Home page
- About Us page
- Contact Us page
- Search destinations
- Beach recommendations
- Temple recommendations
- Mountain recommendations
- Destination images

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## Purpose

The purpose of this project is to provide users with useful
travel recommendations and help them explore different
destinations.
